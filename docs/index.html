dsh-lens · DeepSeek Harness plugin

把页面当成一张可以批注的稿纸。

Codex 风格的界面批注插件：点元素、按住 Shift 框选区域、改样式实时预览，把修改意见一次性发进当前对话。
Codex-style element annotation for DeepSeek Harness — click, Shift-drag, live style preview, one structured message.

打开示例站 · Open the demo → GitHub 仓库 v0.1.0

框选区域

按住 Shift 点或拖，框内元素全收进一条区域批注，容器标 [容器]。

样式实时预览

卡片里的 ⚙ 样式改 font-size、color、padding…，页面当场变，批注写 from → to。

Ctrl+点击即发

写完回车，这一条立即进当前对话；跨页的批注最后一起发。
