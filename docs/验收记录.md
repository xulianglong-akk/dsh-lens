## 通过项（有证据）

### 1. 宿主半侧：只列当前工作区的服务

```
POST /__dsh-lens/api  {method:"detect", args:{root:"D:\\网站", force:true}}
→ services: [{ port:4173, url:"http://127.0.0.1:4173/",
               title:"首页 · 镜记的个人空间",
               reason:"script:scripts/dev-server.mjs" }]
   listening: 61   ← 本机监听端口总数
   scanned: 1      ← 只探测了 1 个「被认领」的端口
```

- 61 个监听端口里只列出 4173；哔哩哔哩客户端的 22331 等噪音完全没有出现。
- 证据来源是**进程命令行里的相对脚本**（`node scripts/dev-server.mjs` 在 `D:\网站` 下存在），
  不是「碰巧这个端口常见」。
- 把 root 换成 `D:\deepseek harness插件`（本次会话工作区，没有 dev server）时返回 `services: []`，
  面板退到「手填地址」形态。

### 2. 预览代理 + 注入

```
POST /__dsh-lens/api  {method:"preview", url:"http://127.0.0.1:4173/"}
→ 200 { url:"http://localhost:51364/", origin:"http://localhost:51364" }
GET http://localhost:51364/ → 200, 84856 bytes
  window.__DSH_LENS__=      ✓
  shim 注入                  ✓
  overlay 注入（当前磁盘版）  ✓
```

站点自己的 `/index.html`、`src/*`、`/api/*` 都走这个 origin，页面标题正确，说明路径与资源都透传成功。

### 3. 框选区域（真实页面）

在首页展开的 1386×799 视口里，从 (30,340) 拖到 (1350,690)，覆盖「我的足迹」「桌游」两张卡片：

```
区域批注: kind=region, rect=1320×350 @ (30,340)
元素收集: count=20, elements=20
  叶子: span.eyebrow「01 / ABOUT ME」/ h2「我的足迹」/ p「去过的地方…」/
        span.feature-corner「个人信息」/ h2「桌游」/ p「故事、推理…」…
  容器: section.home-feature-grid [容器] / a.feature.feature-profile [容器] …
```

- 框内元素「全取到」，容器会标 `[容器]`，SVG 形状（path/circle）被过滤只留 `svg` 本身，避免噪音。
- 拖动过程中实时显示「框选 1320×350 · N 个元素」读数。
- 截图：`docs/img/01-region-draft.png`（卡片打开时的草稿态）、`03-real-host-region-and-style.png`（落库后的框线与 pin）。

### 4. 样式面板（实时预览 + from→to）

点 h1「欢迎来逛逛。」，把 `font-size` 输入框改成 `20px`：

```
改之前计算值: 42.966px
输入 20px 后页面当场: 20px            ← 同一帧生效
保存下来的批注: styleEdits=[{prop:"font-size", from:"42.966px", to:"20px"}]
```

- 只记录**用户真的改过**的属性；font-size 变化会连带 line-height 计算值变化，后者不会被写进批注（已验证）。
- 「复位」按钮恢复这一条改过的所有样式。
- 截图：`docs/img/02-style-panel.png`（六个字段 + 页面已变小 + 区域框线仍在）。

### 5. Ctrl+点击立即发送

`Ctrl+pointerdown/up` 点 `div.feature-copy`：

```
卡片按钮: 保存并发送    提示: Enter 保存 · Esc 取消 · 保存后立即发送
按 Enter 后 overlay → 面板: {type:"send", annotations:[1 条]}   ← 只发这一条
该条内容: selector=…> div.feature-copy（命中 1 个元素）
          rect=279×195 @ (757,387)
          styles.font-size=16px
          text="02 / TABLETOP桌游故事、推理，和围桌而坐的时光。进入桌游"
```

- 不是「发全部」：`annotations` 只有刚写完的那一条；其它待发批注保留在列表里。
- 面板拿到 `send` 后走 Session Controller（`session.beginSubmission` + `session.prompt(..., 'queue', ..., requestId)`），
  与 dsh-annotate 已跑通的投递链路一致。

### 6. 退出标注模式，页面干净

```
退出前: html[data-dl-mode]=picking, .dl-layer 存在, h1 style="font-size: 20px; line-height: 28px;"
退出后: .dl-layer=false, .dl-pin=0, .dl-region=0, .dl-frame=0,
        style[data-dsh-lens]=0, html 上没有 data-dl-mode,
        h1 style=""（属性为空）, 计算 font-size 回到 42.966px
```

- 交互监听全部挂在一个 `AbortController` 上，退出时 abort；`history.pushState/replaceState` 的补丁还原；
  rAF 巡检循环置停；被改过的内联样式逐条还原。
- 面板卸载时额外发 `destroy`，overlay 连消息监听一起摘掉。

### 7. 客户端半侧：三个入口都注册上了

用 Inspect 读**正在运行的 GUI** 的 Slot 树：

```
conversation.view occupants:
  chat (order 0), trajectory (order 10), dsh-lens-view (order 30, active=true)
```

- 证明客户端 bundle 已经被页面加载、`conversation.view` 的「标注」视图注册成功（对话区入口成立）。
- 右侧栏 tab（`sidebar.right.pane.tab` key=dsh-lens）、header 按钮、输入框 dock 走的是 dsh-annotate 同款
  注册路径（同版本已验证），并已在 `lib/client.js` 里全部 `ctx.effect` 包裹。
